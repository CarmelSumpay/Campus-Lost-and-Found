Smart Match Handover Token

🤝 Match Verification QR

Automated reconciliation between Lost and Found reports.

📌 How the User Verifies a Match:
  1. Side-by-Side Comparison: Scanning the QR code opens a reconciliation record that displays the Lost Report and Found Report side by side.
  2. Private Verification Hints: The system compares unique, non-public details entered during reporting, such as a specific sticker ("awa na lang talaga"), a lock screen wallpaper, a serial number, or private verification text ("kulot" or "ea").
  3. Location & Timestamp Alignment: The user checks whether the location and date/time of the lost item align logically with where and when the item was turned in.
  4. Visual & Description Cross-Check: The administrator or user verifies photos and secondary physical descriptions before authorizing the physical handover.
